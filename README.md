# Airbnb Price Prediction

## Project Overview

This project focuses on predicting Airbnb listing prices using machine learning techniques.

The project includes data preprocessing, exploratory data analysis, feature engineering, feature selection, model training and evaluation.

## Dataset

The project uses Airbnb listing and review-related datasets.
